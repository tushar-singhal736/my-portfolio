# my-portfolio

Personal portfolio website built with React and Framer Motion.

## Overview

This repository contains a developer portfolio with animations, responsive design, and contact form integration.

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Build for production

```bash
npm run build
```

## Project structure

- `src/` — React components and app logic
- `public/` — static assets and site manifest
- `src/config/profile.js` — profile data and project links

## Deployment

This app can be deployed to GitHub Pages, Netlify, or Vercel.
